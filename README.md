# Neural Network Based Robot Control

## 🎯 Objective
To replace traditional PID controllers with a Neural Network (and potentially a Transformer-based model) for adaptive robot control.

## 🧠 The AI Connection
- **`llm-from-scratch-python`:** The Transformer architecture (Attention Mechanism) built here will be adapted to process time-series sensor data for robotic control.
- **`math-learning-journey`:** The Backpropagation algorithm (Chain Rule) will be used to train the controller.

## ⚙️ The Hardware Connection
- **`electronics-from-scratch`:** The output of this neural network will control the MOSFET-based motor drivers designed in the electronics repository.
- **`esp32-diy-radar-system`:** The input to this network will come from the sensor fusion techniques developed in the radar project.
